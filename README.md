# 光芽小院 · Sunbud Garden

一个**零依赖、全程序绘制**的原创花园塔防小游戏。两幕六章：种下会发光的花，收集阳光，在夜霉团翻过篱笆前守住小院与清晨。

> 背景音乐默认关闭，只保留操作音效。需要环境音时可在「设置 → 环境音」里打开。

## 在线游玩

**[zhaoyijia-web.github.io/sunbud-garden](https://zhaoyijia-web.github.io/sunbud-garden/)**

## 立即开始

不需要安装任何包，也不需要构建。

1. **直接双击** `index.html`，用 Chrome / Edge / Safari 打开即可游玩并本地存档。
2. 如果浏览器限制本地文件行为，也可以在终端执行：

```bash
cd pvz
python3 -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000
```

推荐使用较新的桌面浏览器；移动端建议横屏游玩。

## 操作

| 操作 | 方式 |
| --- | --- |
| 收集阳光 | 点击/触摸落下的阳光 |
| 选择植物 | 点击种子卡，或按 `1`–`8` |
| 种下植物 | 再点击草坪空格 |
| 取消选择 | 右键 / `Esc` / 再点一次卡片 |
| 铲除植物 | 点「铲子」后点击植物，或按 `C` |
| 暂停 | 点「暂停」、按 `Esc` 或空格 |
| 继续 | 点「继续守护」或按 `Esc` |
| 浏览全部关卡 | 向下滚动，或点击首屏底部的「六座花园 · 向下浏览」 |
| 保存本关进度 | 暂停后点「返回主页面」，每关会各保存一份未完成对局 |

## 夜霉

咕哝团、纸箱客、铁罐客、疾风崽、摇旗手、苔甲卫，以及两位首领：

- **月蚀吞噬者**：第 3 关首领，血量降至阈值时咆哮并召唤新的夜霉
- **永夜钟守**：第 6 关首领，披着钟楼旧钟的苔石巨兽，拥有独立美术与血条

每行最后有一台一次性割草机，会自动冲出清空该行；对首领只能造成一次重创。三星评级取决于通关时剩余割草机数量。

## 存档与声音

- 总进度存档键：`sunbud.garden.save.v1`（`localStorage`）
- 当前总进度存档版本：`3`
- 未完成对局按关卡分别保存：`sunbud.garden.run.v1.1` … `sunbud.garden.run.v1.6`
- 暂停时会自动暂存一次，点「返回主页面」时再确认保存；阳光、植物、夜霉、波次、冷却、割草机和首领状态都会保留
- 再次进入有进度的关卡，会先显示「继续之前的对局 / 重新开始新对局」选择
- 重新开始、通关或清除进度都会移除该关的未完成对局
- 旧存档会自动迁移：解锁第二幕，并将背景音乐保持为关闭
- 玩家之后可以手动在设置里重新打开环境音
- 若浏览器禁止本地存储，游戏仍可运行，但进度只保留在当前页面内，设置里会显示提示

## 技术说明

- **无外部依赖、无构建步骤、无外部素材**：角色、场景、雨、星光、光源、粒子和 UI 装饰都由 Canvas 2D / CSS / SVG 生成。
- **Web Audio API** 实时合成音效与可选的环境拨弦音。
- 固定逻辑分辨率 `1440 × 760`，按可用视口等比缩放；Canvas 内坐标与响应式 DOM 分离。
- 新机制：涟漪水花邻行溅射、棱镜整行穿透光束、破晓钟三行钟波。
- 通用首领系统：月蚀吞噬者与永夜钟守共用血量条、咆哮与召唤、割草机重创逻辑。
- 帧步长上限 `50ms`，避免切后台后跳帧；`prefers-reduced-motion` 会压缩粒子与动效。
